# Vaishvi Patel - AI Engineering & Data Science Portfolio

Interactive, responsive portfolio showcasing work in AI Engineering, Data Science, and Applied LLM systems.

## 🚀 Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Tooling**: Vite 8
- **Styling**: Tailwind CSS v4 + Custom Interactive Animations (Canvas, Glassmorphism)
- **Deployment**: Vite Preview / Static Web Hosting

## 🛠️ Local Development

1. **Install dependencies**:
   ```bash
   pnpm install
   # or
   npm install
   ```

2. **Start the local development server**:
   ```bash
   pnpm dev
   # or
   npm run dev
   ```

3. **Build for production**:
   ```bash
   pnpm build
   # or
   npm run build
   ```
